
# Photoshop Cheat Sheet

## Image Cutouts

1. Import first image as a new layer. 
2. Import second image as a new layer. 
3. Ctrl + Click the thumbnail of the first picture in the Layers panel to load the shape as a selection. 
4. Select the second, background image layer. 
5. Go to **Layer > Raster Mask > Reveal Selection**. 
6. With the shape selection still active, go to **Select > Inverse** (or press *Shift + Ctrl + I*) to select everything outside of the circle. 
7. Press **Delete / Backspace** to erase the area outside the area.
